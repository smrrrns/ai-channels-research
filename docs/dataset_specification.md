# Спецификация датасета

Итоговый файл: [`data/final/ai_publics_dataset.csv`](../data/final/ai_publics_dataset.csv).
10 479 постов из 10 Telegram-каналов, 83 признака, период декабрь 2024 — декабрь 2025.

Полная таблица признаков по группам (сгенерирована `notebooks/refactor.ipynb`): [`dataset_structure.txt`](dataset_structure.txt).

## Единица наблюдения

Одна строка = один пост в одном из 10 каналов.

## Группы признаков

### Метаданные канала
| Признак | Описание |
|---|---|
| `channel_username` | Никнейм канала (без `@`) |
| `channel_title` | Название канала |
| `channel_subscribers` | Число подписчиков на момент сбора |

### Метаданные публикации
| Признак | Описание |
|---|---|
| `post_id` | ID поста в канале |
| `post_date` | Дата публикации, `YYYY-MM-DD` |
| `post_time` | Время публикации, `HH:MM:SS` |
| `post_datetime` | Полная метка времени публикации |
| `scraped_at` | Когда пост был собран сборщиком |
| `is_scheduled` | Признак отложенного поста (эвристика: время публикации кратно 5/10 минутам с секундами `:00`) |

### Контент
| Признак | Описание |
|---|---|
| `text` | Текст поста; если в посте есть опрос — вопрос опроса добавлен через `[ОПРОС] ...` |
| `text_length` | Длина `text` в символах |
| `has_media` | Есть ли вложение |
| `media_type` | `photo` / `document` / `other` / пусто |
| `has_poll` | Есть ли встроенный опрос |
| `has_links_entities` | Есть ли гиперссылки в тексте |
| `links_count_entities` | Количество уникальных гиперссылок |
| `links_from_entities` | Список самих ссылок |

### Вовлечённость
| Признак | Описание |
|---|---|
| `views` | Просмотры |
| `forwards` | Репосты |
| `total_reactions` | Сумма всех реакций на пост |
| `reaction_<эмодзи>` | Одна колонка на каждый встреченный эмодзи-реакцию (например `reaction_🔥`, `reaction_❤️`) — количество этой реакции на пост. Набор колонок не фиксирован и зависит от того, какие реакции встретились в данных |

Кастомные Telegram-реакции (не обычные эмодзи, а платные/анимированные стикеры) переводятся в обычные эмодзи вручную через карту `CUSTOM_REACTIONS_MAP` в [`config/settings.py`](../config/settings.py) — иначе они попали бы в датасет как `custom_<id>`.

## Как получен датасет

1. **`run.py`** — сбор сырых постов по каждому каналу через Telegram API (Telethon) → `data/channels_data/raw/<канал>.csv`.
2. **`notebooks/01_data_cleaning.ipynb`** — объединение всех каналов, приведение кастомных реакций к эмодзи (через `data/channels_data/processed/`), обработка пропусков → `data/final/ai_publics_dataset.csv`.
3. **`notebooks/refactor.ipynb`** — пересчёт статистики и структуры датасета (файлы в этой папке).
4. **`notebooks/analysis.ipynb`** — итоговый анализ и графики (`notebooks/figures/`).

## Известные ограничения
- `is_scheduled` — эвристика по времени публикации, а не факт из API.
- Полнота реакций зависит от `CUSTOM_REACTIONS_MAP`: реакция, для которой нет записи в карте, попадёт в колонку `reaction_custom_<id>` вместо человекочитаемого эмодзи.
